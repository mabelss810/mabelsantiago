Software Engineering & Security — Internship
Pinpointe Listings App — Production Data Integrity & Backend Engineering
Real Production Shipped

Worked as a software engineering and security intern on an internal real-estate tech platform at Pinpointe — a Next.js / TypeScript / Supabase app that ingests landlord emails and PDFs into a searchable apartment database. Discovered a critical data integrity failure in production, rebuilt the broken parser from scratch, reverse-engineered an undocumented third-party API, and shipped all work as reviewed pull requests against a live codebase.

Security & Data Integrity
  • Audited production database and discovered an LLM-based PDF parser fabricating 317 phantom listings — traced root cause to hard-coded example addresses in the model's own prompt; verified zero source occurrences before flagging
  • Identified and removed a production API route bypassing row-level security; documented broker PII fields to keep out of stored data
  • Verified all AI-generated code against real production data before merge — catching multiple cases where AI logic was subtly wrong
Engineering & Systems
  • Replaced non-deterministic AI parser with a deterministic coordinate-based PDF parser — eliminated fabricated data, recovered ~40% more listings, removed all per-call API cost
  • Reverse-engineered an undocumented third-party JSON API using browser DevTools; built an adapter taking production image coverage from 8 to 49 photos on first ingest
  • Re-architected parser from position-based to content-based classification after discovering vendor re-scaled PDFs between issues — preventing a failure mode where empty parse auto-marked entire landlord inventory as rented

Memory Forensics Investigation Lab
Memory Forensics DFIR

Conducted a full memory forensics investigation on a Windows 7 memory image using Volatility 3 — associated with the University of Southern California. Identified two active user sessions from process metadata, reconstructed the attack timeline by tracing parent-child process relationships, and recovered three artifacts from memory alone, with no filesystem access.

Investigation Scope
  • Analyzed a Windows 7 memory image entirely in RAM using Volatility 3, without any filesystem access
  • Identified two active user sessions from process metadata and reconstructed the attack timeline via parent-child process relationships
  • Recovered three artifacts purely from memory: a Base64-encoded batch file on the desktop, a Paint canvas that existed only in memory, and a password-protected RAR archive belonging to a second user
Methodology & Reporting
  • Cracked the NTLM password hash using offline techniques to extract the final password-protected artifact
  • Applied evidence-based methodology to move from process metadata to full artifact recovery without disk access
  • Documented full methodology on GitHub, written spoiler-free so others can learn from the investigation
